# Pacifique Mutuyimana - Personal Portfolio

A responsive personal portfolio website built with HTML and Tailwind CSS, showcasing my background, technical education, awards, and key projects in IT and embedded systems.

## Features

- **About Me Section:** Highlights my background as an IT student and developer specializing in building intelligent embedded systems and digital solutions.
- **Projects Showcase:** Displays technical works, including the Facial Recognition Access Control System.
- **Education & Background:** Outlines academic milestones at SJTC and RP Musanze College.
- **Awards & Certifications:** Recognizes achievements such as the Rwanda Innovation Hub Certificate and SCAD Certificate.
- **Contact Section:** Provides direct communication channels, phone numbers, location (Kigali-Kicukiro), and social media handles.

### Prerequisites
To view or run this project locally, you only need:
* A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.)
* A code editor like [Visual Studio Code](https://code.visualstudio.com/) (optional, for editing)
* Git installed on your computer
